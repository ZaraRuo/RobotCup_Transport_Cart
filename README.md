# RobotCup Transport Cart — 自动搬运机器人

基于 Arduino Mega 2560 的自动搬运机器人。支持黑线循迹、二维码导航、物品搬运等任务。

## 硬件清单

| 硬件 | 数量 | 说明 |
|------|:----:|------|
| Arduino Mega 2560 | 1 | 主控板 |
| 步进电机 + 驱动器 | 2 | 底盘后轮驱动，差速转向 |
| 步进电机 + 驱动器 | 1 | 转盘旋转（72°/144°/216°） |
| 灰度循迹传感器 | 12路 | 前8路 + 后4路，黑线检测 |
| 二维码扫描模块 | 1 | 扫码成功自动串口输出（内容ASCII+CR） |
| 电动推杆 + L298N | 1 | 货物推放（单程 10s 全程） |
| 颜色传感器 | 1 | TCS230（8针），物料五色识别 |

## 引脚分配

参见 [`Transport_Cart/Config.h`](Transport_Cart/Config.h)。

| 模块 | 引脚 | 说明 |
|------|------|------|
| 左轮步进 | DIR=30, PUL=11, EN=31 | 底盘左后轮 |
| 右轮步进 | DIR=32, PUL=12, EN=33 | 底盘右后轮（方向反转） |
| 转盘步进 | DIR=40, PUL=41, EN=42 | 货物转盘 |
| 前侧传感器 | A0~A7 | 8路，从左到右 |
| 后侧传感器 | A8~A11 | 4路，从左到右 |
| 推杆 L298N | IN1=22, IN2=23, ENA=24 | 推杆伸/缩/停止 |
| 二维码 Serial3 | TX=14, RX=15 | 9600bps |
| 颜色传感器 | S0=50, S1=51, S2=52, S3=53, OE=49, OUT=2 | TCS230，中断计数测频 |

二维码模块为自动输出模式：扫码成功后自动发送 内容ASCII+回车(0x0D)，波特率 9600。例：扫"1"→`0x31 0x0D`，扫"5"→`0x35 0x0D`，数字 10~16 为两位 ASCII（如扫"12"→`0x31 0x32 0x0D`）。按 CR/LF 分帧解析为整数（1~16）。

## 接线指南

> 引脚编号均以 [`Config.h`](Transport_Cart/Config.h) 为准；Arduino Mega 2560 为 5V 主控，注意信号电平匹配。

### 1. 步进电机（左后轮 / 右后轮 / 转盘）

驱动器接口为 PUL / DIR / EN 三路信号。**EN 极性：HIGH=脱机（禁用），LOW=使能**（`Stepper::init()` 初始化为 LOW）。

| 电机 | DIR | PUL | EN | 说明 |
|------|-----|-----|-----|------|
| 左后轮 M1 | D30 | D11 | D31 | 底盘左后轮 |
| 右后轮 M2 | D32 | D12 | D33 | 底盘右后轮 |
| 转盘 | D40 | D41 | D42 | 货物转盘（72°倍数） |

- 右后轮无需改线：`Stepper_Init()` 已通过 `setDirInvert(true)` 在软件上反转方向。
- 电机电源（驱动器电源端）独立供电，电压按驱动器/电机规格选择（常见 12V），**必须与主控共地**。

### 2. 灰度循迹传感器（12路）

| 传感器 | Arduino 引脚 | 说明 |
|--------|-------------|------|
| 前侧 Q1~Q8 | A0~A7 | 从左到右排列，前进循迹 |
| 后侧 H1~H4 | A8~A11 | 从左到右排列，后退循迹 |

- 数字量输出：黑线上方为 `1`（`LINE_BLACK`），白底为 `0`（`LINE_WHITE`）。
- 传感器供电 5V，与主控共地。

### 3. 电动推杆（L298N）

| L298N 端子 | Arduino | 说明 |
|-----------|---------|------|
| IN1 | D22 | 方向控制（与 IN2 组合） |
| IN2 | D23 | 方向控制 |
| ENA | D24 | 代码初始化为 HIGH（全速使能） |
| OUT1 / OUT2 | — | 接推杆电机两根线 |
| 电源 VCC/GND | 独立电源 | 电压按推杆规格（常见 12V），与主控共地 |

方向逻辑（`PushRod.cpp`）：

| IN1 | IN2 | 动作 |
|-----|-----|------|
| HIGH | LOW | 伸出 |
| LOW | HIGH | 缩回 |
| LOW | LOW | 停止 |

- 行程控制：推杆无位置反馈，`extendToTop()` / `retractToBottom()` 各运行 `PUSH_ROD_TRAVEL_MS`（10s）后自动停止。

### 4. 二维码扫描模块（ADL615H）

| 模块端子 | Arduino | 说明 |
|---------|---------|------|
| TX | D15（Serial3 RX） | 模块数据输出 → 主控 |
| RX | D14（Serial3 TX） | 预留（自动输出模式不使用） |
| VCC / GND | 5V / GND | 波特率 9600，共地 |

- 自动输出模式：扫码成功后模块自动发送 内容ASCII+回车(0x0D)（如扫"1"→`0x31 0x0D`），**无需触发指令**。
- 若模块 RX 为 3.3V 电平，需确认兼容 5V 逻辑或加电平转换。

### 5. 电源与共地要求

1. 所有模块（电机驱动、传感器、二维码模块）GND 必须与 Arduino GND 相连（共地）。
2. 电机/推杆使用独立电源，禁止从 Arduino 5V 引脚取电。
3. 上电顺序：先接好信号线与共地 → 再上电机/推杆电源 → 最后 USB 连接烧录调试。

### 6. 接线自检（对应调试阶段）

| 检查项 | 调试阶段 | 预期现象 |
|--------|:-------:|---------|
| 推杆伸缩 | 1 | 伸到顶(10s)→伸到底(10s) |
| 传感器读数 | 2 | 串口每500ms输出12路值+偏移量 |
| 单电机转向 | 3 | 左/右轮各正转3000步+反转3000步 |
| 底盘直行 | 4 | 前进300mm→后退150mm→±90° |
| 二维码通讯 | 7 | 扫码后串口打印数字 (1~16) |
| 转盘旋转 | 9 | 72°/144°/216° 往返 |
| 颜色识别 | 10 | 串口打印颜色+RGB（先'w'白平衡） |

### 7. 颜色传感器（TCS230，8针模块）

8 针模块：`S0/S1/S2/S3/OUT/OE` + `VCC/GND`，板上白光 LED 常亮（无独立 LED 控制脚）。

| 模块引脚 | Arduino | 说明 |
|---------|---------|------|
| S0 | D50 | 输出频率缩放（与 S1 组合，代码固定 2%） |
| S1 | D51 | 同上 |
| S2 | D52 | 滤波通道选择（与 S3 组合） |
| S3 | D53 | 同上 |
| OE | D49 | 输出使能，**LOW=开启输出** |
| OUT | D2 | 频率输出 → Mega 外部中断 INT0，上升沿计数 |
| VCC / GND | 5V / GND | 共地 |

- 采样方式：每个通道在 100ms 窗口内用中断统计 OUT 上升沿数（`COLOR_SAMPLE_WINDOW_US`），4 通道一轮约 0.4s，非阻塞。
- 换环境光照后必须重新白平衡：传感器对准白色表面，串口发送 `w`（Stage 10 中）。

## 模块架构

```
Transport_Cart.ino         — 主入口 + 分阶段调试 + 正常模式
├── Config.h               — 引脚定义、系统常量
├── Stepper.h/cpp          — 步进电机非阻塞驱动
├── LineSensor.h/cpp       — 12路灰度传感器 + 加权质心偏移量
├── Chassis.h/cpp          — 底盘状态机（直行/旋转/循迹）
├── PushRod.h/cpp          — 电动推杆（L298N，伸到顶/伸到底 10s）
├── QRScanner.h/cpp        — 二维码扫描（Serial3 自动输出，CR分帧解析）
├── Turntable.h/cpp        — 转盘步进电机（72°旋转 + 5仓位管理 + 颜色识别定位）
├── ColorSensor.h/cpp      — TCS230 颜色识别（中断计数，非阻塞）
└── TaskFlow.h/cpp         — 正常模式任务流程编排（任务1+任务2）
```

## 车辆运动模型

```
          前 (行进方向)
          ┌─────────┐
          │ 万向轮  │ ← 无动力，仅支撑
          │         │
  ← 左    │  车 体  │    右 →
          │         │
     ┌────┤  ┌──┐   ├────┐
     │ M1 │  │  │   │ M2 │ ← 步进主动轮（后轮）
     └────┤  └──┘   ├────┘
          │    ↑    │
          │  190mm  │
          └─────────┘
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 步距角 | 1.8° | 电机规格 |
| 细分数 | 32 | 驱动器设置 |
| 每圈步数 | 6400 | 360÷1.8×32 |
| 轮径 | 70mm | 后轮 |
| 每 mm 步数 | ≈29.10 | 6400÷(π×70) |
| 后轮轮距 | 190mm | 两主动轮中心距 |

### 旋转标定参考（基于 WHEEL_BASE_MM=190）

| 45° | 74.61mm | 2,171 |

## 调试模式

通过宏选择运行模式：

```cpp
#define MAIN_DEBUG          1    // 1=调试，0=正常（代码当前默认 1）
#define DEBUG_STAGE         10   // 调试阶段 (1~12)（代码当前默认 10）
#define DEBUG_MOTOR_BYPASS  0    // 1=电机旁路（只打日志）
```

| Stage | 名称 | 说明 |

| 5 | 前向循迹 | 循迹前进 300000 步，测试修正参数 |
| 6 | 后向循迹 | 循迹后退 10000 步 |
| 7 | 二维码扫描 | 同一接收路径，扫码/电脑串口模拟打印数字 (1~16) |
| 8 | 原地旋转 | 45°/90°/180° CCW+CW，标定用 |
| 9 | 转盘测试 | 72°旋转 + 5仓位占用/定位演示 |
| 10 | 颜色识别 | TCS230 实时识别 + 串口 'w' 白平衡 |
| 11 | 转盘+颜色 | 车头仓转180°识别，'s'全仓扫描记录颜色 |
| 12 | 流程分段测试 | 复用正式流程同一套代码（运动函数/收料/识别/遮蔽） |

### 循迹修正算法

统一修正逻辑（前进/后退共用）：

- **线性比例修正**：偏移 ±25 内按比例递增
- **最大修正**：偏移 > 25 时直接满额修正
- 修正量通过 `TRACK_MAX_CORRECTION_US` 在 `Config.h` 中调参（默认 1000）

以下示例以 `baseUs=80us`（Stage 5 参数）计算：

```
offset=5  → 慢轮 +200us（速差 3.5x）
offset=15 → 慢轮 +600us（速差 8.5x）
offset≥25 → 慢轮 +1000us（速差 13.5x）
```

## 正常模式

`MAIN_DEBUG=0` 时进入正常工作模式，`loop()` 反复调用 `TaskFlow_Update()`（其内部泵动各模块）。

当前流程为**任务2 + 任务1 骨架**（默认先2后1，规则允许自选顺序）：

- **任务2**：出HOME → 右二维码区扫码(1~6)（方案=3个摆放点上各是A/B/C哪个物块）→ **循迹前进**按 **点3→点2→点1** 顺序收满3块 → 一起搬运，按**固定规则** A→冠军台、B→亚军台、C→季军台 摆放3次 → 返回HOME
- **任务1**：出HOME → 左二维码区扫码(1~16) → **循迹前进**沿线收满5个彩色物块（物块在循迹路线上）→ 逐仓转180°识别颜色并记录 → 按方案放到中心目标区A~E → 返回HOME

所有运动原语（出HOME、去二维码区、循迹收料、去目标点、放料动作、返回HOME等 11 个）在 `TaskFlow.cpp` 中以 `TODO(用户)` 留空，需结合场地实测的定距移动/姿态调整参数填写。
