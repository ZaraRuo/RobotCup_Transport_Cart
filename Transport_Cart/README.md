# Transport Cart — 自动搬运机器人

基于 Arduino Mega 2560 的自动搬运机器人基础框架。

## 硬件清单

| 硬件 | 数量 | 引脚 | 说明 |
|------|------|------|------|
| Arduino Mega 2560 | 1 | - | 主控板 |
| 步进电机 | 2 | L:DIR30/PUL11/EN31, R:DIR32/PUL12/EN33 | 底盘驱动 |
| 灰度循迹传感器 | 12路 | A0~A7(前), A8~A11(后) | 黑线检测 |
| 电动伸缩推杆 | 1 | 13 | HIGH伸出/LOW缩回 |
| 二维码扫描模块 | 1 | Serial3(14,15), 115200bps | QR码读取 |

## 车辆运动模型

```
          前 (行进方向)
          ┌─────────┐
          │ 万向轮  │ ← 无动力，仅支撑
          │         │
  ← 左    │  车 体  │    右 →
          │         │
     ┌────┤  ┌──┐   ├────┐
     │ M1 │  │  │   │ M2 │ ← 步进电机主动轮 (后)
     └────┤  └──┘   ├────┘
          │    ↑    │
          │  190mm  │
          └─────────┘
```

| 参数 | 值 | 来源 |
|------|-----|------|
| 车型 | 4轮差速 | 前2万向轮(无动力) + 后2步进主动轮 |
| 步距角 | 1.8° | 电机规格 |
| 细分数 | 32 | 驱动器设置 |
| 每圈步数 | **6,400** | 360÷1.8×32 |
| 轮径 | 70mm | 实测 |
| 轮周长 | 219.91mm | π×70 |
| 每毫米步数 | **29.10** | 6400÷219.91 |
| 后轮轮距 | 190mm | 实测 |

### 旋转标定参考

| 角度 | 每轮弧长 | 每轮步数 |
|------|---------|---------|
| 45° | 74.61mm | 2,171 |
| 90° | 149.22mm | 4,342 |
| 180° | 298.45mm | 8,684 |

## 编译

在 Arduino IDE 中打开 `Transport_Cart.ino`，选择 **Arduino Mega 2560**，验证/上传。

## 调试模式

在 `Transport_Cart.ino` 顶部修改两个宏：

```cpp
#define MAIN_DEBUG       1    // 1=调试, 0=正常工作
#define DEBUG_STAGE      1    // 选择调试阶段 (1~8)
#define DEBUG_MOTOR_BYPASS 0  // 1=电机旁路(只打日志不转)
```

### 调试阶段

| Stage | 名称 | 测试内容 |
|-------|------|---------|
| 1 | 推杆测试 | 伸缩/脉冲 x3 周期 |
| 2 | 传感器读数 | 12路原始值 + 偏移量，实时滚动 |
| 3 | 单电机测试 | 左轮/右轮独立正转1000步+反转1000步 |
| 4 | 底盘直行 | 前进300mm/后退150mm/旋转±90°，不循迹 |
| 5 | 前向循迹 | 循迹前进直至停止线 + 定步循迹15000步 |
| 6 | 后向循迹 | 循迹后退直至停止线 |
| 7 | 二维码扫描 | 轮询Serial3，实时打印扫码结果 |
| 8 | 原地旋转测试 | CCW/CW各45°/90°/180°，标定 WHEEL_BASE_MM |

### 底盘物理量接口

```cpp
Cart.moveMm(300, 160);        // 前进 300mm, 160us/步
Cart.moveMm(-150, 240);       // 后退 150mm, 240us/步
Cart.rotateAngle(90, 160);    // 左转 90° (CCW)
Cart.rotateAngle(-180, 160);  // 右转 180° (CW)
```

精度依赖 `Config.h` 中的标定值：
- `WHEEL_STEPS_PER_MM` (8.5) — 直行距离标定
- `WHEEL_BASE_MM` (180.0) — 旋转角度标定

### 电机旁路模式

```
DEBUG_MOTOR_BYPASS=1
```

不驱动实际电机，只打印 `[MOTOR_BYPASS]` 日志。用于在脱离硬件时验证逻辑。

## 模块架构

```
Transport_Cart.ino        — 主入口 + 分阶段调试
├── Config.h              — 所有引脚定义和常量
├── Stepper.h/cpp         — 步进电机驱动（非阻塞）
├── LineSensor.h/cpp      — 12路灰度传感器
├── Chassis.h/cpp         — 底盘状态机（循迹/直行/旋转）
├── PushRod.h/cpp         — 电动推杆控制
└── QRScanner.h/cpp       — 二维码扫描（Serial3非阻塞）
```
